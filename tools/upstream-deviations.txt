Pinned by tools/core-tests/core.test.mjs "denoise reaches both stages, and no shipped two-stage record bakes 1.0".

Any edge to app.js made the bundler emit the whole old UI as a chunk the React page would fetch mid-generation (measured: app-CrqYddB2.js, 990 kB; after the seam the clean build has 14 chunks and none of them contains initGalleryTab). Pinned by tools/core-tests/core.test.mjs "vram prepare: the report goes to the injected sink with the right tone" and by import-check.mjs check 7, which now walks both static and dynamic edges.
